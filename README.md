# Loan Default Prediction Project

##  Project Overview
This project uses machine learning to predict whether a loan applicant will default or not. It helps the bank reduce financial risk by identifying high-risk applicants.

---

##  Dataset
The dataset contains information about loan applicants such as:
- Income
- Loan amount
- Credit history
- Education
- Property area
- Loan status

---

##  Steps Followed
1. Data loading and exploration
2. Data cleaning and preprocessing
3. Exploratory Data Analysis (10 graphs)
4. Logistic Regression model training
5. Model evaluation

---

##  Model Used
- Logistic Regression (Binary Classification)

---

##  Evaluation Metrics
- Accuracy Score
- Confusion Matrix
- Classification Report

---

##  Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

---

##  Outcome
The model helps predict loan default risk and supports better decision-making for the bank.
